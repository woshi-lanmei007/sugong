# 股市公式（通达信语法）

这套公式按**波段操作**（持股几天到几周）设计，全部没有未来函数：信号一旦出现，之后不会消失或移位。

| 文件 | 类型 | 用途 |
|---|---|---|
| 01-主图-趋势波段 | 主图 | 均线、变色趋势线、20日压力/支撑线、「突破」「回踩」「离场」标记 |
| 02-副图-波段MACD | 副图 | MACD 金叉分强弱（零轴上/下），提示疑似底背离 |
| 03-副图-资金强弱 | 副图 | 估算资金流入/流出（红柱/绿柱），以及近20日相对大盘强弱 |
| 04-选股-放量突破 | 选股 | 创60日新高 + 放2倍量 + 涨3%以上 |
| 05-选股-多头回踩 | 选股 | 均线多头排列时缩量回踩10日线 |
| 06-选股-零轴下二次金叉 | 选股 | MACD 底部二次金叉，且第二次位置更高 |
| 07-选股-强于大盘 | 选股 | 近20日比大盘多涨10%以上的趋势股 |
| 08-预警-放量突破 | 预警 | 盘中出现放量突破时提醒 |
| 09-预警-跌破20日线 | 预警 | 持仓止损提醒 |
| 10-主图-阶梯止盈加仓线 | 主图 | 按成本价画出分批卖出线和加仓线，碰到时做标记 |
| 11-TradingView-阶梯止盈加仓线.pine | TradingView | 美股用：同上，成本价和每档比例都能在指标设置里直接改，可设到价提醒 |
| 阶梯止盈加仓表.html | 计算器 | 填成本价和每档比例，算出每档触发价、股数、利润、持仓均价；可切换美股/A股 |

## 在通达信里导入

1. 按 `Ctrl+F` 打开「公式管理器」（或菜单：功能 → 公式系统 → 公式管理器）。
2. 按文件类型选择分类，然后点「新建」：
   - **主图 / 副图**：选「技术指标公式」。主图要在「画线方法」里选**主图叠加**，副图选**副图**。
   - **选股 / 预警**：选「条件选股公式」。
3. 取一个英文或中文名字（例如 `QSBD`），把 txt 里的内容全部粘贴进去，点「测试公式」，通过后点「确定」。
4. 使用方法：
   - 主图、副图：在 K 线图上直接输入公式名，回车即可。
   - 选股：功能 → 选股器 → 条件选股，选中公式后执行选股。
   - 预警：功能 → 预警系统 → 条件预警设置，加入 08、09，并把 09 的预警范围设成自选股/持仓股。

## 阶梯止盈 / 加仓模型

默认档位（在计算器里可以随意修改）：

**上涨分批卖出**（比例按最初持股数算）

| 涨幅 | +10% | +20% | +30% | +50% | +70% | +100% |
|---|---|---|---|---|---|---|
| 卖出 | 10% | 15% | 15% | 20% | 20% | 剩余全部 |

**下跌分批买入**（比例按计划总资金算）

| 跌幅 | 0%（首次建仓） | −10% | −20% | −30% |
|---|---|---|---|---|
| 买入 | 30% | 20% | 25% | 25% |

- 用法：先用 `阶梯止盈加仓表.html` 算出每档价格，再到通达信里对这只股票设「股价预警」（右键个股 → 加入预警），把这些价格填进去，到价就会提醒。
- `10-主图-阶梯止盈加仓线` 需要先在公式编辑器的「参数」表里加一个参数 `CB`（成本价），详见文件开头的说明。
- 最后一档加仓买完就是满仓，之后再跌不要继续加钱，另外定好止损线。

## 用法建议

- **先看主图的趋势线颜色**：红色（向上）时才考虑「突破」「回踩」买点，绿色时只看不做。
- **用副图做确认**：买点出现时，最好 MACD 在零轴上方，而且资金强弱是红柱。
- **选股结果只是候选名单**，还要人工看一遍 K 线和消息面再决定。
- **盘中信号会随价格变化**：当天没收盘前，突破、跌破的条件可能先满足后又不满足，以收盘为准。

## 美股

- **计算器**默认是美股：金额按美元，股数按 1 股取整，颜色默认绿涨红跌（可切换）。
- **TradingView**：打开 `11-TradingView-阶梯止盈加仓线.pine`，在 TradingView 底部「Pine 编辑器」新建脚本，全部替换为文件内容，保存后「添加到图表」。在指标设置里填成本价，各档涨跌幅和比例也都在设置里改，不用动代码。要到价提醒：图表右键 →「添加提醒」→ 条件选「阶梯止盈加仓线」→ 选「到达卖出档 / 到达清仓档 / 到达加仓档」。
- **富途牛牛 / moomoo、老虎**：可以直接在 App 里给股票设「到价提醒」，把计算器算出的价格填进去即可。
- 01–10 号是通达信公式，按 A 股写的（比如排除 ST 股、按一手 100 股）。美股需要的话可以改写成 TradingView 版本。

## 其他软件

- **同花顺 / 东方财富**：语法和通达信基本相同，大多数可以直接粘贴。如果报错，最常见的是 `DRAWICON` 的图标编号、`NAMELIKE`、`INDEXC` 这几个函数写法不同，把报错行告诉我就能帮你改。
- 参数（如 20 日、1.5 倍量）都直接写在公式里，可以按个人习惯修改。

> 风险提示：技术指标只反映历史价格和成交量，不能保证未来走势，请结合自己的判断并控制仓位。
